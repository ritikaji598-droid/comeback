🔑 AI ke liye free Gemini API key

  1. Browser me aistudio.google.com/apikey kholo aur Google account se login karo.
  2. Create API key → Create key → Copy key. Nayi keys AQ. se shuru hoti hain, ye bilkul sahi hai.
  3. Neeche paste karke Test karo dabao. Hara ✓ aaye to ho gaya.
